# DATA SOURCES

## V1
Primary source: local repository content.

Sources:
- project records
- service records
- experiment records
- approved brand assets
- approved project screenshots/videos

## Source-of-truth rule
A factual claim must have a known source.
Do not scrape third-party websites for portfolio claims.

## External data
Only add external APIs when a concrete product requirement exists.
Document:
- provider
- purpose
- fields used
- retention
- failure behavior
- credentials
- rate limits

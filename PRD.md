# PRD — Onkai Studio Website

## Product statement
A premium, accessible, creative studio website that communicates what Onkai Studio builds, demonstrates real work, presents services, and creates a clear path for potential clients/collaborators to start a project.

## Target audiences
1. Potential clients.
2. People discovering Onkai projects.
3. Developers/designers evaluating the studio.
4. Collaborators and partners.
5. General visitors interested in creative technology.

## Primary user journeys
### Journey A — Discover
Home -> Work -> Project -> Contact.

### Journey B — Client
Home -> Services -> Work -> Contact.

### Journey C — Product explorer
Home -> Work -> Playground -> Project.

### Journey D — About
Home -> Studio -> Work -> Contact.

## Required pages
- /
- /work
- /work/[slug]
- /services
- /studio
- /playground
- /contact
- /privacy
- /terms if required

## Homepage sections
1. Navigation.
2. Hero.
3. What Onkai makes.
4. Featured work.
5. Studio/playground statement.
6. Selected experiments.
7. Services.
8. Contact CTA.
9. Footer.

## Content principles
Show real work and real project status.
Do not fabricate social proof.

## Success criteria
- Visitor understands Onkai within seconds.
- Visitor can discover work quickly.
- Visitor can navigate entirely with keyboard.
- Visitor can contact the studio without confusion.
- A developer can add a project without changing core UI components.
- Site remains usable with reduced motion.
- Lighthouse/accessibility checks are treated as engineering signals, not vanity targets.

## Out of scope for V1
- User accounts.
- CMS unless later justified.
- E-commerce.
- Admin dashboard.
- Database-backed portfolio.
- AdMob on the company website.

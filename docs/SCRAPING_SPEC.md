# SCRAPING SPEC

No scraping is required for V1.

If scraping is introduced later:
- Have a documented business purpose.
- Respect robots.txt and applicable terms/laws.
- Use rate limits.
- Identify source URLs.
- Cache responsibly.
- Never scrape personal/private information.
- Do not bypass authentication, paywalls, CAPTCHA, or access controls.
- Validate and sanitize imported data.
- Keep provenance for every imported record.
- Provide a deletion/update strategy.

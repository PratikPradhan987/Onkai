# ASSET GUIDE

## Brand assets
Place approved Onkai logo assets under:
public/logo/

## Project assets
Use:
public/projects/<project-slug>/

Recommended:
- hero.webp
- thumbnail.webp
- screenshots/
- video/ only when necessary

## Rules
- Use descriptive filenames.
- Optimize raster images before committing.
- Prefer WebP/AVIF where appropriate.
- Do not store duplicate assets.
- Keep source/original design files outside the web bundle unless required.

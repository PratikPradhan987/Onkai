# TESTING

## Unit tests
Test pure utilities, validation and transformations.

## Component tests
Test:
- accessible names
- keyboard interaction
- conditional states
- form validation
- error states

## E2E tests
Minimum critical journeys:
1. Homepage navigation.
2. Work listing.
3. Project detail.
4. Contact form validation.
5. Contact success/failure.
6. Mobile navigation.
7. Keyboard-only navigation.

## Accessibility testing
Automate where possible and manually inspect:
- keyboard navigation
- focus visibility
- heading structure
- landmarks
- forms
- reduced motion
- contrast

## Regression rule
Every fixed bug that can reasonably recur should gain a regression test.

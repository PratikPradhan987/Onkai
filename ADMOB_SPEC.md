# ADMOB SPEC

AdMob is NOT used on the Onkai Studio company website.

This document is a reusable policy for future Onkai mobile apps/games.

Rules:
- Monetization must not compromise accessibility or core UX.
- Ads must follow current Google AdMob policies.
- Never place ads over critical controls.
- Never encourage accidental clicks.
- Handle ad-load failure gracefully.
- Test ad behavior separately from production monetization.
- Keep ad configuration out of unrelated website modules.
